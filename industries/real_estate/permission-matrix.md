# Real Estate Permission Matrix

| Role | Main Capabilities |
| --- | --- |
| Real Estate Director | Full portfolio, approvals, reports, billing visibility, commissions, valuations, land, development |
| Real Estate Branch Manager | Branch operations, properties, units, leases, listings, utility billing, amenities, maintenance, reports |
| Property Manager | Properties, units, tenants, amenities, maintenance, inspections, utility visibility |
| Leasing Officer | Tenants, tenant offboarding, leases, rent billing, utility billing, tenant ledger visibility |
| Accountant | Billing, utility charges, tenant ledgers, statements, reports, Finance, ETIMS |
| Customer Service | Tenant lookup, service requests, amenity bookings, tenant ledger visibility, communication |
| Super Admin | Permanent deletion of record-free tenants only |
