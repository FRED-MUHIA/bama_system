# Retail Permission Matrix

| Role | Core Access |
| --- | --- |
| Super Admin | All permissions through existing platform super admin behavior |
| Retail Director | View/manage retail, reports, analytics, and all operational read access |
| Store Manager | POS, products, inventory, customers, loyalty, gift cards, returns, scanning, compliance overrides, reports |
| Branch Manager | Branch operations, orders, customers, inventory visibility, scan reporting, reports |
| Cashier | POS, product lookup, customer lookup, loyalty lookup, gift card lookup, returns lookup, scanning, self-checkout support |
| Warehouse Manager | Inventory, warehousing, orders, procurement visibility, batch compliance, scan reports |
| Warehouse Staff | Inventory, warehousing, order visibility, scan visibility |
| Customer Service | Customers, loyalty, returns, and order visibility |
| Accountant | Retail reports, POS visibility, returns visibility, shared finance visibility |
| Auditor | Retail reports, analytics, and shared audit log visibility |

ETIMS permissions are shared compliance permissions:

- `etims.view`
- `etims.manage`
- `etims.reports`
- `etims.retry`
